# Paradise Nursery

Paradise Nursery is a simple plant shop web application built with React, Vite, and Redux Toolkit.

## Features
- Landing page with a "Get Started" button
- Company information page
- Plant products grouped by category
- Add plants to the shopping cart
- Increase or decrease item quantities
- Remove products from the cart
- Cart item count and subtotal calculation

## Run locally
1. Install Node.js (LTS).
2. Open a terminal in this project folder.
3. Run `npm install`.
4. Run `npm run dev`.
5. Open the local URL shown in the terminal.

## Project structure
- `src/App.jsx` - main landing page and app navigation
- `src/App.css` - page styles and landing background image
- `src/components/AboutUs.jsx` - company details
- `src/components/ProductList.jsx` - product catalogue
- `src/components/CartItem.jsx` - shopping cart page
- `src/redux/CartSlice.jsx` - cart reducer actions
- `src/redux/store.js` - Redux store

This is a student project for learning React state management and shopping cart functionality.
